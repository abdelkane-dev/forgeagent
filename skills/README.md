# ForgeAgent Skills for Agensi.io

Ce dossier contient les deux packages de compétences officiels prêts à être listés sur [Agensi.io](https://agensi.io) conformément aux échanges avec Joeri Brons.

---

## 📂 Contenu du dossier

### 1. `forgeagent-architect/` — **Gratuit (Free)**
* **Fichiers** : `SKILL.md`, `README.md`, `references/spec-schema.json`.
* **Rôle** : Conçoit des agents Claude et audite la sécurité des serveurs MCP selon les principes de moindre privilège de ForgeAgent.
* **Modèle** : Gratuit pour attirer du trafic, des avis positifs et faire connaître ForgeAgent.

### 2. `forgeagent-evaluator/` — **Payant (10 €)**
* **Fichiers** : `SKILL.md`, `README.md`, `references/test-suite-template.json`, `scripts/eval-runner.mjs`.
* **Rôle** : Harnais d'évaluation et tests de non-régression automatisés sur 100 points pour empêcher la dégradation des agents en production.
* **Modèle** : Payant à **10 €** (tu touches 70 % nets, soit 7 € par vente).

---

## 🚀 Comment les publier sur Agensi.io ce week-end

1. Connecte-toi sur ton compte [Agensi.io](https://agensi.io).
2. Clique sur **"List a Skill"** ou **"Publish"**.
3. Pour chaque skill :
   * **Titre** : Le nom du dossier (ex: `ForgeAgent Architect & Security Guard`).
   * **Description** : Copie-colle le contenu du fichier `README.md` du dossier correspondant.
   * **Prix** : `0 €` pour Architect / `10 €` pour Evaluator.
   * **Fichiers / Repository** : Téléverse l'archive ZIP du sous-dossier (ou indique le lien GitHub vers le dossier `skills/<nom-du-skill>`).
4. Valide la publication !
